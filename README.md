# TickTick Arabic Advanced

> نسخة الويب تجريبية وتخزن البيانات في المتصفح فقط؛ راجع [حدود نسخة الويب](docs/WEB.md) وصدّر بياناتك دوريًا. ملفات EXE ليست ضمن مستودع Git، ويمكن بناؤها محليًا باستخدام `npm run dist`.

> Web support is experimental. Data stays in this browser; see [web limitations](docs/WEB.md). Executables are not committed; build them locally with `npm run dist`.

تطبيق مهام وإنتاجية سطح مكتب لنظام ويندوز، عربي أولًا، يعمل **بالكامل دون إنترنت**، مع مزامنة اختيارية رسمية مع حساب TickTick.

An offline-first Arabic/English productivity desktop app for Windows, with optional official TickTick account sync.

- **الإصدار / Version:** 1.0.0
- **المنصة / Platform:** Windows 10/11 x64
- **التقنيات / Stack:** Electron 45.1.0 · React 19 · TypeScript 5.9 · Vite 7 · `node:sqlite`
- **الحالة / Status:** يعمل ومُختبر محليًا (105 اختبار وحدة + 30 فحص E2E + فحص النسخ المُحزَّمة)

## 1. التثبيت والتشغيل / Install & Run

### ملفات جاهزة / Ready artifacts

| الملف | الوصف | الحجم |
|---|---|---|
| `release/TickTick-Arabic-Advanced-1.0.0-portable.exe` | نسخة محمولة، لا تحتاج تثبيت | ~105 MB |
| `release/TickTick-Arabic-Advanced-1.0.0-setup.exe` | مثبّت NSIS (للمستخدم الحالي، مع اختيار مجلد التثبيت) | ~116 MB |
| `release/win-unpacked/` | نسخة غير مضغوطة للتشغيل المباشر | — |

- لحساب بصمة الملفات المحلية بعد بنائها: `Get-FileHash release\*.exe -Algorithm SHA256`.

> الملفات غير موقّعة رقميًا (لا توجد شهادة توقيع)، لذا قد يعرض Windows SmartScreen تحذيرًا عند أول تشغيل. هذا متوقع في البناء المحلي.

### أول تشغيل / First run

1. شغّل الملف المحمول أو ثبّت التطبيق.
2. تُنشأ قاعدة البيانات تلقائيًا في:
   `%APPDATA%\TickTick Arabic Advanced\ticktick-arabic.db`
3. يبدأ التثبيت الجديد بالعربية واتجاه RTL والثيم الفاتح `Daylight`؛ تبقى اختيارات الثيم المحفوظة مسبقًا دون تغيير.
4. يمكن تحميل بيانات تجريبية من **الإعدادات ← البيانات ← تحميل بيانات تجريبية**، أو البدء بقائمة فارغة.

لا يحتاج التطبيق إلى حساب أو إنترنت لأي ميزة أساسية.

### قاعدة بيانات جاهزة / Ready seeded database

يمكن إنشاء `seed/ticktick-arabic.db` محليًا عبر `npm run build` ثم `npm run seed` (4 مشاريع، 23 مهمة، 4 عادات، 3 عدّادات). لا تُنشر قاعدة البيانات في المستودع. لاستخدامها:

```powershell
# أغلق التطبيق أولًا، ثم:
Copy-Item .\seed\ticktick-arabic.db "$env:APPDATA\TickTick Arabic Advanced\ticktick-arabic.db" -Force
```

أو استخدم زر **تحميل بيانات تجريبية** داخل التطبيق. تُنشأ القاعدة تلقائيًا إن لم تكن موجودة.

## 2. الميزات / Features

### المهام / Tasks
- مشاريع وقوائم ذكية: اليوم، غدًا، الأيام السبعة القادمة، المتأخرة، المكتملة، سلة المهملات.
- مهام فرعية (متداخلة)، قوائم تحقق، ملاحظات، وسوم، أولويات (منخفضة/متوسطة/عالية).
- تاريخ بدء واستحقاق ووقت ومدة، ومهام طوال اليوم.
- تكرار: يومي، أيام العمل، أسبوعي، كل أسبوعين، شهري، سنوي، وقواعد RRULE مخصّصة مدعومة.
- تذكيرات متعددة لكل مهمة مع تأجيل (Snooze) وإشعارات داخل التطبيق.
- مرفقات (روابط ومسارات ملفات محلية)، قوالب مهام، نسخ مهمة، نقل بين المشاريع.
- إعادة ترتيب بالسحب، وسحب المهام إلى لوحة كانبان أو التقويم.
- تراجع/إعادة (Undo/Redo) لعمليات الإنشاء والتعديل والحذف والإكمال.
- حذف ناعم وسلة محذوفات مع استرجاع أو حذف نهائي.
- بحث شامل، لوحة أوامر (Command Palette)، وإضافة سريعة بلغة طبيعية.

**الإضافة السريعة تفهم:** `#وسم`، `@مشروع`، `!high` / `!1`، `اليوم`، `غدًا`، `بعد غد`، أسماء الأيام، `10:30`، وتواريخ مثل `2026-11-02`.

### التقويم / Calendar
- عروض: يوم، أسبوع، شهر، سنة، وأجندة قادمة.
- بداية الأسبوع قابلة للضبط (السبت افتراضيًا).
- أحداث مستقلة، أحداث متكررة، وسحب المهام/الأحداث لإعادة الجدولة.
- خط الوقت الحالي ومؤشر "الآن"، وفتح التقويم قرب ساعات العمل.
- تصدير/استيراد ICS.

### كانبان / Kanban
- أعمدة قابلة للضبط لكل مشروع، سحب وإفلات، عدّادات، وإنشاء سريع داخل العمود.

### المخطط الزمني / Timeline
- عرض المهام ذات المدد على محور زمني، مناسب لتخطيط الحمل اليومي.

### مصفوفة أيزنهاور / Eisenhower Matrix
- أربعة أرباع (عاجل/مهم…) مع تصنيف تلقائي أو يدوي، وسلة "غير مصنّفة".

### العادات / Habits
- عادات يومية/أسبوعية بهدف كمي، تسجيل يومي، سلاسل إنجاز (Streaks)، خريطة حرارية، وملاحظات.

### التركيز / Focus (Pomodoro)
- مؤقت تركيز/استراحة قصيرة/طويلة، إعدادات قابلة للضبط، بدء تلقائي، صوت، وربط جلسة بمهمة.
- لتغيير مدة التركيز مباشرةً، افتح **التقدم والتركيز ← التركيز**، وأدخل عدد الدقائق ثم اضغط **تطبيق المدة**. إذا كانت جلسة جارية أو متوقفة مؤقتًا، اضغط **إعادة الضبط** أولًا.
- تكتكة اختيارية أثناء تشغيل المؤقت؛ من **الإعدادات ← بومودورو ← صوت تكتكة الساعة** يمكن إيقافها دون إيقاف تنبيه النهاية. يلزم أيضًا تفعيل إعداد الصوت الرئيسي للمؤقت.
- سجل جلسات وهدف يومي بالدقائق.

### الإحصائيات / Statistics
- إنجاز اليوم/الأسبوع/الشهر، المفتوح والمتأخر، نسبة الإنجاز، دقائق التركيز، والتزام العادات.
- رسوم بيانية لآخر 7/30/90 يومًا، وأداء المشاريع.

### العدّادات التنازلية والملاحظات اللاصقة / Countdowns & Sticky notes
- عدّادات بتكرار سنوي، وملاحظات لاصقة ملوّنة على مساحة عمل.

### التخصيص / Customization
- عربي RTL افتراضيًا، وإنجليزية LTR بتبديل فوري.
- 6 ثيمات: Midnight، Daylight، Ocean، Sand، Forest، Rose، مع لون تمييز.
- وضع كثيف (Dense)، شريط جانبي قابل للطي، إخفاء/إظهار أرقام الأسابيع، تنسيق 12/24 ساعة.

### البيانات / Data
- SQLite محلي، معاملات متداخلة آمنة (Savepoints) ونسخ احتياطي.
- نسخ احتياطي يدوي، **تلقائي يومي عند التشغيل**، ونسخة قبل كل مزامنة وقبل أي استرجاع.
- استرجاع نسخة احتياطية مع فحص صلاحيتها أولًا، وحفظ نسخة أمان قبل الاستبدال.
- تصدير/استيراد: JSON (حزمة كاملة)، CSV (مهام)، ICS (تقويم)، مع منع التكرار عند الاستيراد.
- إعادة تعيين قاعدة البيانات من الإعدادات (مع تأكيد).

### المزامنة الاختيارية / Optional sync
- OAuth2 رسمي عبر `ticktick.com/oauth/authorize` و`/oauth/token`، وواجهة `api.ticktick.com/open/v1`.
- الاتجاه الافتراضي: **وارد فقط (Inbound)**؛ والخيار الثنائي متاح صراحةً.
- رموز الوصول تُشفَّر عبر Windows DPAPI (`safeStorage`) ولا تُكتب نصًا صريحًا.
- مزامنة تلقائية بفاصل زمني، سجل مزامنة، حل التعارضات (محلي/بعيد)، ومعالجة الحذف البعيد.
- قطع الاتصال يحذف الرموز ويُبقي البيانات المحلية.
- إعادة بناء البيانات من الخادم متاحة يدويًا.

### واجهة برمجة محلية / Local API
- خادم REST على `127.0.0.1` (معطّل افتراضيًا) مع رمز Bearer لكل تثبيت.
- نقاط النهاية: `/api/health`، `/api/tasks` (GET/POST)، `/api/projects`، `/api/habits`.

## 3. إعداد مزامنة TickTick / TickTick sync setup

1. أنشئ تطبيقًا في بوابة مطوّري TickTick واحصل على `Client ID` و`Client Secret`.
2. أضف Redirect URI مطابقًا، مثل: `http://127.0.0.1:17832/callback`.
3. في التطبيق: **المزامنة ← أدخل Client ID / Client Secret / Redirect URI ← حفظ**.
4. اضغط **ربط الحساب**، وأكمل التفويض في المتصفح.
5. اختر الاتجاه (وارد فقط أو ثنائي) والفاصل الزمني، ثم **مزامنة الآن**.

> **لم يُختبر الاتصال بحساب TickTick حقيقي** أثناء التطوير لعدم توفر بيانات اعتماد. تم التحقق من عناوين OAuth وواجهة API الحيّة (استجابات 401/200 المتوقعة) واختبار منطق المزامنة محليًا. راجع `docs/TEST-REPORT.md`.

## 4. التطوير / Development

```bash
npm install
npm run dev          # Vite + Electron في وضع التطوير
npm run build        # بناء main + preload + renderer
npm start            # تشغيل البناء المحلي
npm test             # 105 اختبار وحدة/تكامل
npm run test:e2e     # 30 فحص E2E عبر Playwright Electron
npm run dist         # حزمة محمولة + مثبّت NSIS
npm run dist:portable
```

المتطلبات: Node.js 22.12+ (تم البناء على Node 26) وWindows x64.

### بنية المشروع / Project structure

```
electron/main/     # العملية الرئيسية: DB، المستودع، المزامنة، النسخ الاحتياطي، IPC
electron/preload/  # جسر آمن (contextBridge) — لا وصول مباشر لـ Node من الواجهة
shared/            # أنواع، تواريخ، تكرار، فلاتر، إحصاءات، استيراد/تصدير، i18n
src/               # React: الصفحات والمكوّنات والمخزن
src/views/         # 12 صفحة (مهام، تقويم، كانبان، …)
src/components/    # محرر المهمة، الإضافة السريعة، الشريط الجانبي، الرسوم…
tests/             # Vitest + E2E + فحوصات i18n/IPC
docs/              # تقرير الاختبار، قائمة الميزات، تحليل TickTick
```

**الفصل بين الطبقات:** الواجهة (React) تتحدث مع العملية الرئيسية عبر IPC فقط؛ العملية الرئيسية تملك SQLite والملفات والمزامنة؛ `shared/` منطق نقي قابل للاختبار.

## 5. الخصوصية / Privacy

- لا تتبّع، لا تحليلات، لا إرسال بيانات دون مزامنة صريحة.
- لا قراءة لبيانات TickTick الشخصية، ولا استخدام لملفات تعريف الارتباط أو رموز تطبيق TickTick المثبّت.
- الاتصال الوحيد بالشبكة هو OAuth/API الرسمي عند تفعيل المزامنة.
- الرموز مشفّرة بـ DPAPI، وقاعدة البيانات محلية غير مشفّرة (تعتمد على تشفير القرص في Windows).
