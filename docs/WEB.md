# نسخة الويب / Web version

نسخة الويب تستخدم SQLite عبر `sql.js` وتحفظ لقطة قاعدة البيانات في IndexedDB داخل المتصفح والجهاز الحاليين. لا توجد مزامنة بين الأجهزة. احفظ نسخة خارجية بانتظام من الإعدادات عبر تصدير JSON؛ حذف بيانات الموقع أو استخدام التصفح الخاص قد يؤدي إلى فقد البيانات.

لحماية البيانات من تعارض الكتابة، يتطلب التطبيق Web Locks API واتصال HTTPS أو عنوان localhost، ولا يسمح بفتح نسختين للكتابة في الوقت نفسه. إذا ظهر تنبيه بوجود تبويب آخر، أغلقه ثم أعد تحميل الصفحة.

مزامنة TickTick وواجهة API المحلية ونسخ ملفات قاعدة البيانات وفتح أو إرفاق الملفات المحلية ميزات خاصة بسطح المكتب وليست متوفرة في نسخة الويب. لا تُشغَّل التذكيرات عندما تكون صفحة الويب مغلقة. دعم التشغيل دون اتصال بعد التحميل الأول غير مضمون: لا يوجد service worker.

```sh
npm run build:web
npm run preview:web
npm run test:web
```

يستخدم اختبار الويب Edge أو Chrome المحلي على Windows؛ يمكن تحديد متصفح آخر عبر `CHROME_PATH`. ملف البناء الناتج في `dist/web`، والمسارات نسبية لتناسب GitHub Pages داخل مستودع فرعي.
