## 6. ما لم يُختبر / Not tested

هذه العناصر **لا** ندّعي نجاحها:

1. **المزامنة بحساب TickTick حقيقي** — لا تتوفر بيانات اعتماد OAuth. تم التحقق من:
   - `https://api.ticktick.com/open/v1` يعيد 401 بدون رمز (متوقع).
   - `https://ticktick.com/oauth/authorize` يعيد 200.
   - `https://ticktick.com/oauth/token` يعيد 401 بدون بيانات (متوقع).
   - منطق التدفق والصراعات والحذف مغطى بالكود واختبارات محلية، لكنه لم يُشغَّل مقابل خادم فعلي.
2. **إشعارات Windows الأصلية** — تُستدعى `new Notification(...)` عند تفعيل الإشعارات، لكن لم يتم التحقق آليًا من ظهورها أو من الصوت.
3. **السحب والإفلات** — منفّذ في التقويم/كانبان/القوائم، لكن E2E لا يحاكي السحب (يُختبر التحديث عبر IPC).
4. **الاستيراد من ملفات ICS/CSV حقيقية كبيرة** — المحللات مغطاة باختبارات وحدات، لا بملفات مستخدم فعلية.
5. **توقيع الكود** — الملفات غير موقّعة.
6. **تعدد الشاشات / DPI العالي** — لم يُختبر على إعدادات متعددة.
7. **الترقية من إصدار أقدم** — لا يوجد إصدار سابق؛ ترحيل المخطط موجود لكنه غير مُختبر على قاعدة بيانات قديمة حقيقية.
